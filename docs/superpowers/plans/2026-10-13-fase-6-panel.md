# Fase 6 — Panel del operador: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** El operador entra a `/panel` con su contraseña, ve los traspasos abiertos y los chats de todos los negocios, toma, devuelve o responde una conversación, y consulta la auditoría y el costo de IA por cita.

**Architecture:** Páginas HTML generadas por la propia API (NestJS) con un helper `html` que escapa toda interpolación, un guard de sesión por cookie y CSRF, y lecturas negocio por negocio con `runInTenant` (RLS sigue aplicando). Las respuestas del operador entran al outbox existente como `origin='operator'` y salen por la cola `outbound` con `jobId` = id de la fila. Dos tablas globales (`operators`, `operator_sessions`), una columna mantenida por trigger (`conversations.last_message_at`) y una columna de atribución (`appointments.booked_by`).

**Tech Stack:** NestJS 11 + Express 5, TypeORM (SQL a mano), Postgres 16, Redis (ioredis) para el límite de intentos, `node:crypto` (scrypt, HMAC), Luxon, Vitest + supertest. Sin dependencias nuevas.

**Spec:** `docs/superpowers/specs/2026-09-03-plataforma-whatsapp-citas-design.md` v2.3 — §3.7 (panel), §4.1 (tablas), §6 (control), §7.1 (outbox).

## Global Constraints

- Commits: Conventional Commits en español, `tipo(scope): descripción`, **un solo `-m`, sin cuerpo ni Co-Authored-By**.
- No se reutiliza código de `f16` ni de `node-meta`.
- Sin dependencias nuevas: `node:crypto`, `ioredis` (ya está), Luxon (ya está).
- Las lecturas entre negocios van **negocio por negocio con `runInTenant`**; ningún rol salta RLS. Un `tenant_id` nunca se toma del cliente: el slug se resuelve a id en `tenants` y la conversación se busca dentro de ese contexto (si no está, 404).
- `operators` y `operator_sessions`: globales, **sin RLS**. La app: `operators` solo `SELECT`; `operator_sessions` `SELECT, INSERT, UPDATE, DELETE`. Ambas en `PRESUPUESTO` y en una lista explícita de exentas.
- Contraseña: `scrypt` (`N=2^15, r=8, p=1`, 32 bytes, sal de 16), formato `scrypt$N$r$p$sal$hash` en base64url; comparación con `timingSafeEqual`; hash señuelo para correos inexistentes. Mínimo **12** caracteres.
- Cookie `citara_op`: 32 bytes aleatorios en base64url, `HttpOnly`, `SameSite=Strict`, `Path=/panel`, `Secure` cuando `PUBLIC_BASE_URL` es `https://`. En BD solo `sha256(token)`. Vence a las **12 h sin uso** y a los **7 días** en todo caso.
- Límite: **5 fallos en 15 minutos** por correo y por IP, en Redis. Sin Redis el login **falla cerrado** (503).
- CSRF: `HMAC-SHA256(clave = token de sesión, "csrf")` en base64url, campo `_csrf` de cada formulario POST; además un `Origin` presente y distinto del de `PUBLIC_BASE_URL` da 403.
- Cabeceras en toda página del panel: CSP `default-src 'none'; script-src 'nonce-X'; style-src 'nonce-X'; connect-src 'self'; form-action 'self'; base-uri 'none'; frame-ancestors 'none'`, `X-Frame-Options: DENY`, `Cache-Control: no-store`, `Referrer-Policy: no-referrer`.
- Locks: las acciones sobre una conversación la bloquean con **`FOR NO KEY UPDATE`**, nunca `FOR UPDATE` (choca con el `FOR KEY SHARE` de los inserts que la referencian; ver el comentario en `flow-runner.service.ts`).
- Responder: texto de **1 a 4096** caracteres tras `trim`; exige ventana de 24 h abierta (`canSendFreeform`), negocio `active` y canal `active`. Encolar **tras el commit**. «Reintentar» solo sobre filas `operator` en `pending`.
- Auditoría: toda acción del panel con `actor = 'operator:<id>'`. Acciones nuevas: `control.to_operator` (tomar algo que ya era de un humano) y `message.operator_sent`.
- Costo por cita = USD de `agent_runs` del mes ÷ citas **creadas** en el mes (cualquier estado), por negocio, con los límites del mes en su zona horaria. Sin citas: «—».
- Respuestas al usuario y textos de la UI en español. Decir «los tests», nunca «suite».
- `pnpm typecheck` y `pnpm test` en verde al final de cada task.

## Review Focus

1. **Texto del cliente con HTML o comillas** (`<script>`, `"><img onerror>`, `</textarea>`) en nombre de perfil, `saved_name`, cuerpo, `details` de auditoría o nombre del negocio → se muestra como texto en todas las pantallas y en los fragmentos de refresco. Tests en Task 4 (helper) y Task 9/11 (pantallas).
2. **Conversación de otro negocio con el slug de uno propio** (`/panel/negocios/a/conversaciones/<id de b>`) en GET y en cada POST → 404 sin efectos. Tests en Task 8 y Task 10.
3. **Doble clic o recarga al responder** (mismo `envio`) → una sola fila y un solo envío. Test en Task 10.
4. **Sesión vencida mientras la página refresca sola** → el fragmento no inyecta la página de login dentro del chat: el script recarga la página completa. Test en Task 7 (respuesta del fragmento sin sesión) y verificación manual en el navegador al final.
5. **Concurrencia del trigger de `last_message_at`** (eco y turno sobre la misma conversación; recordatorios en lote) → ningún job se cuelga; un deadlock detectado por Postgres se reintenta. Test en Task 2.

- [ ] **Step 3: Migración**

```ts
import type { MigrationInterface, QueryRunner } from 'typeorm';

/** Exportado para el test del relleno. */
export const BACKFILL_SQL = `
  UPDATE conversations c SET last_message_at = m.at
    FROM (SELECT conversation_id, max(occurred_at) AS at FROM messages GROUP BY conversation_id) m
   WHERE m.conversation_id = c.id`;

/**
 * Última actividad de cada conversación, para ordenar la bandeja del panel
 * (spec §3.7.2) sin recorrer `messages`. La mantiene un trigger: cubre todos
 * los puntos que insertan mensajes (turno, eco, historial, recordatorios,
 * agente, operador) sin tocar ninguno. Con `occurred_at` y la condición `<`,
 * un mensaje viejo del historial no la mueve.
 *
 * El UPDATE toma el lock de la fila de la conversación. El turno ya lo tiene
 * (upsert de `persist`) y el agente lo toma antes de escribir (`finish`), así
 * que ahí no cambia nada. Un barrido de recordatorios que choque con un turno
 * puede dar un deadlock que Postgres detecta y la cola reintenta; nunca un
 * cuelgue, porque ningún camino espera en Node a otra conexión con la fila tomada.
 */
export class AddLastMessageAtToConversations1725800200000 implements MigrationInterface {
  public async up(q: QueryRunner): Promise<void> {
    await q.query(`ALTER TABLE conversations ADD COLUMN last_message_at timestamptz`);
    await q.query(BACKFILL_SQL);
    await q.query(
      `CREATE INDEX conversations_last_message ON conversations (tenant_id, last_message_at DESC, id DESC)`);
    await q.query(`
      CREATE FUNCTION touch_conversation_last_message() RETURNS trigger
        LANGUAGE plpgsql SET search_path = pg_catalog, public, pg_temp AS $$
      BEGIN
        UPDATE public.conversations SET last_message_at = NEW.occurred_at
         WHERE id = NEW.conversation_id
           AND (last_message_at IS NULL OR last_message_at < NEW.occurred_at);
        RETURN NULL;
      END $$
    `);
    await q.query(`
      CREATE TRIGGER messages_touch_conversation AFTER INSERT ON messages
        FOR EACH ROW EXECUTE FUNCTION touch_conversation_last_message()
    `);
  }

  public async down(q: QueryRunner): Promise<void> {
    await q.query(`DROP TRIGGER messages_touch_conversation ON messages`);
    await q.query(`DROP FUNCTION touch_conversation_last_message()`);
    await q.query(`ALTER TABLE conversations DROP COLUMN last_message_at`);
  }
}
```

/**
 * HTML del panel. Toda interpolación se escapa salvo que sea SafeHtml (otro
 * html`` o un raw() puesto a propósito): el panel muestra texto que escriben
 * los clientes, y un olvido aquí es un XSS sobre la sesión del operador.
 */
export class SafeHtml {
  constructor(readonly value: string) {}
  toString() { return this.value; }
}

export type HtmlValue = SafeHtml | string | number | null | undefined | false | HtmlValue[];

export const escapeHtml = (s: string) =>
  s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;').replace(/'/g, '&#39;');

/** Solo para HTML que arma el propio código, nunca para datos. */
export const raw = (s: string) => new SafeHtml(s);

const render = (v: HtmlValue): string => {
  if (v === null || v === undefined || v === false) return '';
  if (v instanceof SafeHtml) return v.value;
  if (Array.isArray(v)) return v.map(render).join('');
  return escapeHtml(String(v));
};

export function html(strings: TemplateStringsArray, ...values: HtmlValue[]): SafeHtml {
  let out = strings[0];
  values.forEach((v, i) => { out += render(v) + strings[i + 1]; });
  return new SafeHtml(out);
}

import { randomBytes, scrypt as scryptCb, timingSafeEqual, type ScryptOptions } from 'node:crypto';

export const MIN_PASSWORD_LENGTH = 12;
const N = 2 ** 15, R = 8, P = 1, KEYLEN = 32;
// 128·N·r = 32 MiB: justo el maxmem por defecto de Node, que lo rechaza.
const MAXMEM = 64 * 1024 * 1024;

const scrypt = (pw: string, salt: Buffer, opts: ScryptOptions) =>
  new Promise<Buffer>((ok, ko) => scryptCb(pw.normalize('NFKC'), salt, KEYLEN, opts, (e, k) => (e ? ko(e) : ok(k))));

/** `scrypt$N$r$p$sal$hash`: los parámetros viajan con el hash para poder subirlos sin migrar. */
export async function hashPassword(pw: string): Promise<string> {
  const salt = randomBytes(16);
  const key = await scrypt(pw, salt, { N, r: R, p: P, maxmem: MAXMEM });
  return `scrypt$${N}$${R}$${P}$${salt.toString('base64url')}$${key.toString('base64url')}`;
}

export async function verifyPassword(pw: string, stored: string): Promise<boolean> {
  const parts = stored.split('$');
  if (parts.length !== 6 || parts[0] !== 'scrypt') return false;
  const [n, r, p] = parts.slice(1, 4).map(Number);
  // Parámetros fuera de rango: un hash corrupto, o uno que tumbaría el proceso.
  if (!(n >= 2 ** 14 && n <= 2 ** 20 && (n & (n - 1)) === 0 && r >= 1 && r <= 32 && p >= 1 && p <= 4)) return false;
  const expected = Buffer.from(parts[5], 'base64url');
  if (expected.length !== KEYLEN) return false;
  const key = await scrypt(pw, Buffer.from(parts[4], 'base64url'), { N: n, r, p, maxmem: MAXMEM * 4 });
  return timingSafeEqual(key, expected);
}

let dummy: Promise<string> | null = null;
/** Para un correo que no existe: se verifica contra esto y tarda lo mismo que una clave mala. */

import type { DataSource } from 'typeorm';

export const SESSION_COOKIE = 'citara_op';
export const IDLE_HOURS = 12;
export const ABSOLUTE_DAYS = 7;

export interface OperatorSession { sessionId: string; operatorId: string; email: string; csrf: string }

/** Token CSRF de la sesión: no se guarda y no se puede calcular sin la cookie. */
export const csrfFor = (token: string) => createHmac('sha256', token).update('csrf').digest('base64url');

export function sameSecret(a: string, b: string): boolean {
  const x = Buffer.from(a), y = Buffer.from(b);
  return x.length === y.length && timingSafeEqual(x, y);
}

export async function createSession(
  ds: DataSource, operatorId: string, meta: { ip: string | null; userAgent: string | null },
): Promise<string> {
  const token = randomBytes(32).toString('base64url');
  await ds.query(`DELETE FROM operator_sessions WHERE operator_id = $1 AND expires_at <= now()`, [operatorId]);
  await ds.query(
    `INSERT INTO operator_sessions (operator_id, token_hash, expires_at, ip, user_agent)
     VALUES ($1, $2, now() + make_interval(days => $3), $4, $5)`,
    [operatorId, sha256(token), ABSOLUTE_DAYS, meta.ip?.slice(0, 64) ?? null, meta.userAgent?.slice(0, 512) ?? null]);
  return token;
}

export async function findSession(ds: DataSource, token: string): Promise<OperatorSession | null> {
  const [s] = await ds.query(
    `SELECT s.id, s.operator_id, o.email, s.last_seen_at < now() - interval '1 minute' AS stale
       FROM operator_sessions s JOIN operators o ON o.id = s.operator_id
      WHERE s.token_hash = $1 AND s.expires_at > now()
        AND s.last_seen_at > now() - make_interval(hours => $2) AND o.disabled_at IS NULL`,
    [sha256(token), IDLE_HOURS]);
  if (!s) return null;
  // Se renueva como mucho una vez por minuto: el refresco del chat pide cada 5 s.
  if (s.stale) await ds.query(`UPDATE operator_sessions SET last_seen_at = now() WHERE id = $1`, [s.id]);
  return { sessionId: s.id, operatorId: s.operator_id, email: s.email, csrf: csrfFor(token) };
}

  await ds.query(`DELETE FROM operator_sessions WHERE token_hash = $1`, [sha256(token)]);

import { createHash } from 'node:crypto';
import Redis from 'ioredis';

export const MAX_FAILURES = 5;
export const WINDOW_SECONDS = 15 * 60;
const PREFIX = 'panel-login:';

export class LimiterUnavailableError extends Error {}

/**
 * Fallos de login por correo y por IP (spec §3.7.1). Sin Redis no se sabe si
 * alguien está probando contraseñas: el login falla cerrado.
 */
export class LoginLimiter {
  private readonly redis: Redis;

  constructor(url: string) {
    this.redis = new Redis(url, { maxRetriesPerRequest: 1, commandTimeout: 1000, lazyConnect: true });
    this.redis.on('error', () => {}); // se reporta en cada llamada, no tumba el proceso
  }

  private keys(email: string, ip: string) {
    const e = createHash('sha256').update(email.trim().toLowerCase()).digest('hex');
    return { email: `${PREFIX}email:${e}`, ip: `${PREFIX}ip:${ip}` };
  }

  private async run<T>(fn: () => Promise<T>): Promise<T> {
    try { return await fn(); } catch (err) { throw new LimiterUnavailableError((err as Error).message); }
  }

  blocked(email: string, ip: string): Promise<boolean> {
    const k = this.keys(email, ip);
    return this.run(async () => (await this.redis.mget(k.email, k.ip)).some((v) => Number(v) >= MAX_FAILURES));
  }

  fail(email: string, ip: string): Promise<void> {
    const k = this.keys(email, ip);
    // SET NX EX fija la ventana con el primer fallo; INCR no la alarga.
    return this.run(async () => {
      await this.redis.multi()
        .set(k.email, '0', 'EX', WINDOW_SECONDS, 'NX').incr(k.email)
        .set(k.ip, '0', 'EX', WINDOW_SECONDS, 'NX').incr(k.ip)
        .exec();
    });
  }

  succeed(email: string): Promise<void> {
    return this.run(async () => { await this.redis.del(this.keys(email, '-').email); });
  }

  /** Para los tests. */
  ttl(email: string): Promise<number> { return this.run(() => this.redis.ttl(this.keys(email, '-').email)); }
  reset(): Promise<void> {
    return this.run(async () => {
      const keys = await this.redis.keys(`${PREFIX}*`);
      if (keys.length) await this.redis.del(...keys);
    });
  }

  async close(): Promise<void> { this.redis.disconnect(); }
}

import {
  ArgumentsHost, CanActivate, Catch, ExceptionFilter, ExecutionContext, ForbiddenException,
  HttpException, HttpStatus, Injectable,
} from '@nestjs/common';
import type { Request, Response } from 'express';
// Import de VALOR: parámetro del constructor de un provider Nest.
import { DataSource } from 'typeorm';
import { findSession, sameSecret, SESSION_COOKIE, ABSOLUTE_DAYS, type OperatorSession } from './sessions';
import { newNonce, type PageCtx } from './layout';

export interface PanelRequest extends Request { operator?: OperatorSession; sessionToken?: string }

export function readCookie(req: Request, name: string): string | null {
  for (const part of (req.headers.cookie ?? '').split(';')) {
    const i = part.indexOf('=');
    if (i > 0 && part.slice(0, i).trim() === name) return decodeURIComponent(part.slice(i + 1).trim());
  }
  return null;
}

/** Solo rutas del panel: un `next` hacia fuera sería una redirección abierta. */
export function safeNext(next: unknown): string {
  if (typeof next !== 'string' || next.length > 512) return '/panel';
  if (!/^\/panel(\/[\w\-/]*)?(\?[^\\]*)?$/.test(next) || next.includes('..') || next.includes('//')) return '/panel';
  return next;
}

const publicOrigin = () => new URL(process.env.PUBLIC_BASE_URL ?? 'http://localhost:3000').origin;

export const sessionCookie = {
  name: SESSION_COOKIE,
  options: () => ({
    httpOnly: true, sameSite: 'strict' as const, path: '/panel',
    secure: (process.env.PUBLIC_BASE_URL ?? '').startsWith('https://'),
    maxAge: ABSOLUTE_DAYS * 24 * 3600 * 1000,
  }),
};

/**
 * Un `Origin` presente y ajeno (incluido el opaco `null`) es otro sitio
 * enviando el formulario. Sin `Origin` decide el token CSRF.
 */
export function foreignOrigin(req: Request): boolean {
  const origin = req.headers.origin;
  return typeof origin === 'string' && origin !== publicOrigin();
}

export class LoginRequired extends HttpException {
  constructor(readonly next: string) { super('Inicia sesión', HttpStatus.SEE_OTHER); }
}

@Catch(LoginRequired)
export class LoginRedirectFilter implements ExceptionFilter {
  catch(e: LoginRequired, host: ArgumentsHost) {
    host.switchToHttp().getResponse<Response>()
      .redirect(303, `/panel/login?next=${encodeURIComponent(safeNext(e.next))}`);
  }
}

@Injectable()
export class PanelGuard implements CanActivate {
  constructor(private readonly ds: DataSource) {}

  async canActivate(ctx: ExecutionContext): Promise<boolean> {
    const req = ctx.switchToHttp().getRequest<PanelRequest>();
    const token = readCookie(req, SESSION_COOKIE);
    const session = token ? await findSession(this.ds, token) : null;
    const read = req.method === 'GET' || req.method === 'HEAD';
    if (!session) {
      if (read) throw new LoginRequired(req.originalUrl);
      throw new ForbiddenException('Tu sesión venció. Vuelve a entrar.');
    }
    if (!read) {
      const sent = (req.body as Record<string, unknown> | undefined)?._csrf;
      if (typeof sent !== 'string' || !sameSecret(sent, session.csrf) || foreignOrigin(req)) {
        throw new ForbiddenException('La solicitud no vino del panel.');
      }
    }
    req.operator = session;
    req.sessionToken = token!;
    return true;
  }
}

export const pageCtx = (req: PanelRequest): PageCtx =>
  ({ nonce: newNonce(), csrf: req.operator!.csrf, email: req.operator!.email });

import type { OutboundContent } from '@citara/shared';

export const CHAT_LIMIT = 200;

export interface ChatMessage { id: string; direction: 'in' | 'out'; origin: string; status: string | null; at: Date; text: string }
export interface ChatView {
  conversationId: string; contactName: string | null; waId: string; mode: string; channelId: string;
  channelStatus: string; tenantStatus: string; control: 'bot' | 'human'; reason: string | null;
  humanUntil: Date | null; lastInboundAt: Date | null; messages: ChatMessage[]; hasPendingOperator: boolean;
}

/** Lo interactivo y las plantillas como texto legible; un adjunto como su tipo. */
export function describeMessage(r: { direction: string; type: string; body: string | null; payload: unknown }): string {
  const p = r.direction === 'out' ? (r.payload as OutboundContent | null) : null;
  switch (p?.kind) {
    case 'buttons': return `${p.body}\n${p.buttons.map((b) => `[${b.title}]`).join(' ')}`;
    case 'list': return `${p.body}\n${p.sections.flatMap((s) => s.rows).map((x) => `[${x.title}]`).join(' ')}`;
    case 'template': return `Plantilla «${p.name}»`;
    default: return r.body ?? `[${r.type}]`;
  }
}

/** Corre dentro de runInTenant: una conversación de otro negocio no existe (null). */
export async function loadConversation(m: EntityManager, conversationId: string): Promise<ChatView | null> {
  const [c] = await m.query(
    `SELECT c.id, c.control, c.human_until, c.control_reason, c.last_inbound_at, c.channel_id,
            ct.wa_id, coalesce(ct.saved_name, ct.name) AS contact_name,
            ch.mode, ch.status AS channel_status, t.status AS tenant_status
       FROM conversations c
       JOIN contacts ct ON ct.id = c.contact_id
       JOIN whatsapp_channels ch ON ch.id = c.channel_id
       JOIN tenants t ON t.id = c.tenant_id
      WHERE c.id = $1`, [conversationId]);
  if (!c) return null;
  const rows: { id: string; direction: 'in' | 'out'; origin: string; status: string | null; type: string;
                body: string | null; payload: unknown; occurred_at: Date }[] = await m.query(
    `SELECT * FROM (
       SELECT id, direction, origin, status, type, body, payload, occurred_at, created_at, seq
         FROM messages WHERE conversation_id = $1
        ORDER BY occurred_at DESC, created_at DESC, seq DESC NULLS LAST LIMIT $2) x
     ORDER BY occurred_at, created_at, seq NULLS FIRST`, [conversationId, CHAT_LIMIT]);
  const [{ pending }] = await m.query(
    `SELECT EXISTS (SELECT 1 FROM messages WHERE conversation_id = $1 AND origin = 'operator' AND status = 'pending') AS pending`,
    [conversationId]);

```ts
import type { DataSource } from 'typeorm';
import { runInTenant } from '../tenancy/tenant-context';
import { describeMessage } from './conversation';
import { panelTenants, type PanelTenant } from './tenants';

export const PAGE_SIZE = 50;

export interface InboxRow {
  tenant: PanelTenant; conversationId: string; contactName: string | null; waId: string;
  mode: 'cloud_api' | 'coexistence'; control: 'bot' | 'human'; reason: string | null; humanUntil: Date | null;
  lastMessageAt: Date; lastDirection: 'in' | 'out' | null; lastPreview: string;
}
export interface InboxFilter { tab: 'traspasos' | 'todas'; slug?: string; before?: { at: Date; id: string } }
type Cursor = { at: Date; id: string };

const SELECT = `
  SELECT c.id, c.control, c.human_until, c.control_reason, c.last_message_at,
         ct.wa_id, coalesce(ct.saved_name, ct.name) AS contact_name, ch.mode,
         lm.direction, lm.type, lm.body, lm.payload
    FROM conversations c
    JOIN contacts ct ON ct.id = c.contact_id
    JOIN whatsapp_channels ch ON ch.id = c.channel_id
    LEFT JOIN LATERAL (
      SELECT direction, type, body, payload FROM messages m
       WHERE m.conversation_id = c.id ORDER BY m.occurred_at DESC, m.created_at DESC LIMIT 1) lm ON true`;

/**
 * La bandeja de todos los negocios, negocio por negocio con su contexto de
 * RLS (spec §3.7): una consulta que olvide el contexto devuelve cero filas,
 * no las de otro cliente.
 */
export async function loadInbox(ds: DataSource, f: InboxFilter, now = new Date()): Promise<{ rows: InboxRow[]; next: Cursor | null }> {
  const tenants = (await panelTenants(ds)).filter((t) => !f.slug || t.slug === f.slug);
  const all: InboxRow[] = [];
  for (const tenant of tenants) {
    const raw: any[] = await runInTenant(ds, tenant.id, (m) => f.tab === 'traspasos'
      ? m.query(`${SELECT} WHERE c.control = 'human' AND c.human_until > $1 AND c.last_message_at IS NOT NULL`, [now])
      : m.query(`${SELECT}
          WHERE c.last_message_at IS NOT NULL
            AND ($1::timestamptz IS NULL OR (c.last_message_at, c.id) < ($1::timestamptz, $2::uuid))
          ORDER BY c.last_message_at DESC, c.id DESC LIMIT $3`,
          [f.before?.at ?? null, f.before?.id ?? null, PAGE_SIZE + 1]));
    for (const r of raw) {
      all.push({
        tenant, conversationId: r.id, contactName: r.contact_name, waId: r.wa_id, mode: r.mode,
        control: r.control, reason: r.control_reason, humanUntil: r.human_until, lastMessageAt: r.last_message_at,
        lastDirection: r.direction ?? null,
        lastPreview: r.direction ? describeMessage(r).slice(0, 140) : '',
      });
    }
  }
  const byRecent = (a: InboxRow, b: InboxRow) =>
    b.lastMessageAt.getTime() - a.lastMessageAt.getTime() || (b.conversationId > a.conversationId ? 1 : -1);
  if (f.tab === 'traspasos') {
    // Primero donde nadie más va a contestar: cloud_api con el cliente esperando.
    const waiting = (r: InboxRow) => (r.mode === 'cloud_api' && r.lastDirection === 'in' ? 0 : 1);
    all.sort((a, b) => waiting(a) - waiting(b) || byRecent(a, b));
    return { rows: all, next: null };
  }
  all.sort(byRecent);
  const rows = all.slice(0, PAGE_SIZE);
  const last = rows[rows.length - 1];
  return { rows, next: all.length > PAGE_SIZE ? { at: last.lastMessageAt, id: last.conversationId } : null };
}
```
Nota: la comparación de `id` en memoria (`>` de strings) debe coincidir con el orden de Postgres para uuid; ambos comparan los 16 bytes en el mismo orden que el texto hexadecimal en minúsculas, así que coinciden.

  if (typeof v !== 'string') return undefined;

  const at = new Date(iso);

import type { EntityManager } from 'typeorm';
import { recordAudit } from '../audit/audit';
import { giveControlToHuman, humanInControl, readControl, returnControlToBot } from '../conversations/control';
import { canSendFreeform } from '../conversations/session-window';
import type { MessageOutboundJob } from '../queues/outbound.queue';

export const MAX_TEXT = 4096;

export class PanelActionError extends Error {
  constructor(readonly code: 'no_encontrada' | 'texto' | 'ventana' | 'negocio' | 'canal') { super(code); }
}

export const ACTION_NOTICE: Record<PanelActionError['code'], string> = {
  no_encontrada: 'Esa conversación no existe.',
  texto: `Escribe entre 1 y ${MAX_TEXT} caracteres.`,
  ventana: 'El cliente no ha escrito en las últimas 24 h: WhatsApp solo deja escribirle con una plantilla.',
  negocio: 'El negocio no está activo: no sale nada.',
  canal: 'El canal de WhatsApp está desconectado.',
};

/**
 * Bloquea la conversación como el agente (FOR NO KEY UPDATE, no FOR UPDATE:
 * ese choca con el FOR KEY SHARE de los inserts que la referencian). Corre
 * dentro de runInTenant: una conversación de otro negocio no aparece.
 */
async function lock(m: EntityManager, conversationId: string) {
  const [c] = await m.query(
    `SELECT c.id, c.channel_id, c.last_inbound_at, ct.wa_id, ch.status AS channel_status, t.status AS tenant_status
       FROM conversations c
       JOIN contacts ct ON ct.id = c.contact_id
       JOIN whatsapp_channels ch ON ch.id = c.channel_id
       JOIN tenants t ON t.id = c.tenant_id
      WHERE c.id = $1 FOR NO KEY UPDATE OF c`, [conversationId]);
  if (!c) throw new PanelActionError('no_encontrada');
  return c as { id: string; channel_id: string; last_inbound_at: Date | null; wa_id: string; channel_status: string; tenant_status: string };
}

const actor = (operatorId: string) => `operator:${operatorId}`;

export async function takeControl(
  m: EntityManager, a: { tenantId: string; conversationId: string; operatorId: string; now: Date },
): Promise<void> {
  await lock(m, a.conversationId);
  const before = await readControl(m, a.conversationId);
  await giveControlToHuman(m, { tenantId: a.tenantId, conversationId: a.conversationId, from: a.now,
                                reason: 'operator', actor: actor(a.operatorId) });
  // giveControlToHuman audita el paso de bot a humano; pasar de otro humano al
  // operador también es una acción del panel y queda registrada.
  if (humanInControl(before, a.now) && before.reason !== 'operator') {
    await recordAudit(m, { tenantId: a.tenantId, actor: actor(a.operatorId), action: 'control.to_operator',
                           conversationId: a.conversationId, details: { from: before.reason } });
  }
}

export async function returnControl(
  m: EntityManager, a: { tenantId: string; conversationId: string; operatorId: string },
): Promise<void> {
  await lock(m, a.conversationId);
  await returnControlToBot(m, { tenantId: a.tenantId, conversationId: a.conversationId,
                                cause: 'operator', actor: actor(a.operatorId) });
}

export async function sendOperatorMessage(
  m: EntityManager,
  a: { tenantId: string; conversationId: string; operatorId: string; text: string; submissionId: string; now: Date },
): Promise<{ job: MessageOutboundJob; created: boolean }> {
  const text = a.text.trim();
  if (!text || text.length > MAX_TEXT) throw new PanelActionError('texto');
  const c = await lock(m, a.conversationId);
  const job = (messageId: string): MessageOutboundJob =>
    ({ tenantId: a.tenantId, channelId: c.channel_id, conversationId: c.id, to: c.wa_id, messageId });

  // Con la fila bloqueada, dos POST del mismo envío no pueden pasar a la vez.
  const [dup] = await m.query(
    `SELECT id FROM messages WHERE conversation_id = $1 AND origin = 'operator' AND payload->>'submissionId' = $2`,
    [c.id, a.submissionId]);
  if (dup) return { job: job(dup.id), created: false };

  if (c.tenant_status !== 'active') throw new PanelActionError('negocio');
  if (c.channel_status !== 'active') throw new PanelActionError('canal');
  if (!canSendFreeform(c.last_inbound_at, a.now)) throw new PanelActionError('ventana');

  // El bot no puede contestarle encima: enviar da (o alarga) el control del operador.
  await takeControl(m, a);
  const [row] = await m.query(
    `INSERT INTO messages (tenant_id, conversation_id, direction, origin, type, body, payload, status)
     VALUES ($1, $2, 'out', 'operator', 'text', $3, $4, 'pending') RETURNING id`,
    [a.tenantId, c.id, text, JSON.stringify({ kind: 'text', body: text, submissionId: a.submissionId })]);
  await recordAudit(m, { tenantId: a.tenantId, actor: actor(a.operatorId), action: 'message.operator_sent',
                         conversationId: c.id, details: { messageId: row.id } });
  return { job: job(row.id), created: true };
}

/** Solo lo que nunca salió: un `unconfirmed` pudo llegar y no se reenvía a ciegas. */
export async function pendingOperatorJobs(
  m: EntityManager, a: { tenantId: string; conversationId: string },
): Promise<MessageOutboundJob[]> {
  const rows: { id: string; channel_id: string; wa_id: string }[] = await m.query(
    `SELECT msg.id, c.channel_id, ct.wa_id
       FROM messages msg JOIN conversations c ON c.id = msg.conversation_id JOIN contacts ct ON ct.id = c.contact_id
      WHERE msg.conversation_id = $1 AND msg.origin = 'operator' AND msg.status = 'pending'
      ORDER BY msg.created_at`, [a.conversationId]);
  return rows.map((r) => ({ tenantId: a.tenantId, channelId: r.channel_id, conversationId: a.conversationId,
                            to: r.wa_id, messageId: r.id }));
}

   * Para «reintentar» del panel: BullMQ ignora un add con el id de un job que
   * ya terminó, así que uno fallido o completado se quita antes. Uno que espera
   * o está en curso se deja: ya va a salir.

  async requeue(job: OutboundJob): Promise<void> {
    const existing = await this.queue.getJob(outboundJobId(job));
    if (existing) {
      const state = await existing.getState();
      if (state !== 'failed' && state !== 'completed') return;
      await existing.remove();
    }
    await this.add(job);
  }

import type { DataSource } from 'typeorm';
import { runInTenant } from '../tenancy/tenant-context';
import { panelTenants, type PanelTenant } from './tenants';
import { PAGE_SIZE } from './inbox';

export interface AuditRow {
  tenant: PanelTenant; id: string; at: Date; actor: string; action: string;
  conversationId: string | null; details: Record<string, unknown>;
}
export interface AuditFilter { slug?: string; action?: string; conversationId?: string; before?: { at: Date; id: string } }

const likePrefix = (s: string) => s.replace(/[\\%_]/g, (c) => `\\${c}`) + '%';

export async function loadAudit(ds: DataSource, f: AuditFilter) {
  const tenants = (await panelTenants(ds)).filter((t) => !f.slug || t.slug === f.slug);
  const all: AuditRow[] = [];
  for (const tenant of tenants) {
    const rows: any[] = await runInTenant(ds, tenant.id, (m) => m.query(
      `SELECT id, created_at, actor, action, conversation_id, details FROM audit_log
        WHERE ($1::text IS NULL OR action LIKE $1)
          AND ($2::uuid IS NULL OR conversation_id = $2)
          AND ($3::timestamptz IS NULL OR (created_at, id) < ($3::timestamptz, $4::uuid))
        ORDER BY created_at DESC, id DESC LIMIT $5`,
      [f.action ? likePrefix(f.action) : null, f.conversationId ?? null, f.before?.at ?? null, f.before?.id ?? null, PAGE_SIZE + 1]));
    for (const r of rows) all.push({ tenant, id: r.id, at: r.created_at, actor: r.actor, action: r.action,
                                     conversationId: r.conversation_id, details: r.details });
  }
  all.sort((a, b) => b.at.getTime() - a.at.getTime() || (b.id > a.id ? 1 : -1));
  const rows = all.slice(0, PAGE_SIZE);
  const last = rows[rows.length - 1];
  return { rows, next: all.length > PAGE_SIZE ? { at: last.at, id: last.id } : null };
}

import { DateTime } from 'luxon';
import type { DataSource } from 'typeorm';
import { runInTenant } from '../tenancy/tenant-context';
import { panelTenants, type PanelTenant } from './tenants';

/** La zona del operador: solo decide qué mes se muestra por defecto. */
export const PANEL_ZONE = 'America/Bogota';

export interface CostRow {
  tenant: PanelTenant; agentUsd: number; interpretUsd: number; calls: number; failed: number;
  budgetUsd: number | null; enabled: boolean | null; appointments: number; byAgent: number; byFlow: number;
  usdPerAppointment: number | null;
}

export function parseMonth(v: unknown, now = new Date()): { year: number; month: number } {
  const m = typeof v === 'string' ? /^(\d{4})-(\d{2})$/.exec(v) : null;
  if (m && Number(m[2]) >= 1 && Number(m[2]) <= 12) return { year: Number(m[1]), month: Number(m[2]) };
  const d = DateTime.fromJSDate(now).setZone(PANEL_ZONE);
  return { year: d.year, month: d.month };
}

// Límites del mes en la zona del negocio, como AiGate.monthSpend.
const BOUNDS = `
  WITH b AS (SELECT (make_timestamp($1, $2, 1, 0, 0, 0) AT TIME ZONE t.timezone) AS lo,
                    ((make_timestamp($1, $2, 1, 0, 0, 0) + interval '1 month') AT TIME ZONE t.timezone) AS hi
               FROM tenants t WHERE t.id = $3)`;

export async function loadCosts(ds: DataSource, ym: { year: number; month: number }): Promise<CostRow[]> {
  const out: CostRow[] = [];
  for (const tenant of await panelTenants(ds)) {
    const row = await runInTenant(ds, tenant.id, async (m) => {
      const [runs] = await m.query(`${BOUNDS}
        SELECT coalesce(sum(r.usd) FILTER (WHERE r.kind = 'agent'), 0) AS agent_usd,
               coalesce(sum(r.usd) FILTER (WHERE r.kind = 'interpret'), 0) AS interpret_usd,
               count(r.id)::int AS calls, count(r.id) FILTER (WHERE r.error IS NOT NULL)::int AS failed
          FROM b LEFT JOIN agent_runs r ON r.created_at >= b.lo AND r.created_at < b.hi`,
        [ym.year, ym.month, tenant.id]);
      // Cuentan aunque luego se cancelaran: el gasto para agendarlas ya se hizo.
      const [apps] = await m.query(`${BOUNDS}
        SELECT count(a.id)::int AS total, count(a.id) FILTER (WHERE a.booked_by = 'agent')::int AS by_agent
          FROM b LEFT JOIN appointments a ON a.created_at >= b.lo AND a.created_at < b.hi`,
        [ym.year, ym.month, tenant.id]);
      const [cfg] = await m.query(`SELECT enabled, monthly_budget_usd FROM agent_configs WHERE is_active`);
      return { runs, apps, cfg };
    });
    const agentUsd = Number(row.runs.agent_usd), interpretUsd = Number(row.runs.interpret_usd);
    out.push({
      tenant, agentUsd, interpretUsd, calls: row.runs.calls, failed: row.runs.failed,
      budgetUsd: row.cfg ? Number(row.cfg.monthly_budget_usd) : null, enabled: row.cfg ? row.cfg.enabled : null,
      appointments: row.apps.total, byAgent: row.apps.by_agent, byFlow: row.apps.total - row.apps.by_agent,
      usdPerAppointment: row.apps.total ? (agentUsd + interpretUsd) / row.apps.total : null,
    });
  }
  return out;
}
